2 · Estrategia experimental

Seguimiento de tendencia

Reglas deterministas en Python · se actualiza cada día tras el cierre de Xetra
{% if gold_strategy %} {% set prm = gold_strategy.audit.params if gold_strategy.audit else {} %} {% if prm %}
Cómo funciona
  1. Filtro de tendencia. Solo se buscan compras si el cierre está por encima de la media de las últimas {{ prm.filter_sma }} sesiones.
  2. Entrada por ruptura. Señal cuando el cierre supera el máximo de las {{ prm.entry_breakout }} sesiones anteriores; la orden se ejecutaría en la apertura siguiente.
  3. Stop inicial por volatilidad. Entrada − {{ prm.atr_multiple }}×ATR{{ prm.atr_window }} (rango medio diario).
  4. Tamaño por riesgo. Se arriesga como máximo un {{ prm.risk_pct }}% del capital por operación: cuanto más lejos el stop, menor la posición.
  5. Salida. Cuando el cierre toca el stop inicial o pierde el mínimo de las {{ prm.exit_low }} sesiones previas.

Las estrategias de tendencia aciertan pocas veces (30-40% es normal) y ganan con unas pocas operaciones grandes.
